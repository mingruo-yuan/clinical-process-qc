### 0.1 一页总览：先判断病理类型，再进入对应路径

| 病理类型 | 初始治疗主轴 | 术后/后续主轴 |
|---|---|---|
| DTC：PTC / FTC / OTC | 外科为主；低危PTC可主动监测；手术范围按大小、肉眼ETE、N/M状态、RAI需求决定 | 术后按复发风险决定RAI；LT4替代并动态决定TSH抑制；少数高局部风险行EBRT；RAIR进展后系统治疗 |
| DHGTC / PDTC | 通常按滤泡上皮来源癌外科原则争取完整切除；局部侵袭性更高 | RAI获益取决于碘摄取；残留/广泛淋巴结可考虑EBRT；RAIR进展后按ASCO系统治疗 |
| MTC | 全甲状腺切除为主；中央区清扫地位更重要；按cN和Ctn决定侧颈范围；MEN2需先排除PHEO | 不行RAI；不做肿瘤目的TSH抑制；Ctn+CEA驱动随访；高局部风险EBRT；晚期按RET状态系统治疗 |
| ATC | 快速MDT分期+气道评估+分子分型；仅可切除病例考虑手术，目标R0/R1；多数不可切除病例不以激进手术为主 | 放疗/系统治疗为核心；BRAF V600E优先达拉非尼+曲美替尼；其他靶点/方案个体化 |


## 第一部分  术前推荐检查

> **提示**
> 临床使用方法
> 先完成1.1“所有拟手术甲状腺癌的共性检查”，再根据术前病理/高度疑似类型进入1.2 DTC、1.3 MTC或1.4 ATC/PDTC专病追加检查。

### 1.1 所有拟手术甲状腺癌：共同术前评估

| 项目 | 推荐内容 | 主要页码 |
|---|---|---|
| 病史与查体 | 头颈部放射史、甲状腺癌/综合征家族史；肿块生长速度、声嘶、吞咽困难、呼吸困难、咯血；完整头颈部和颈淋巴结查体。再次手术者回顾既往手术记录和病理。 | 国家卫健委 PDF 2–4；CSCO 2025 PDF 47（书内35） |
| 基础实验室 | 血常规、肝肾功能、甲状腺功能；拟有创操作/手术者加凝血功能等。再次手术者重点查血钙、血磷、PTH。 | 国家卫健委 PDF 4；CSCO PDF 47（35） |
| 高分辨率颈部超声 | 评估甲状腺原发灶、肉眼甲状腺外侵犯及中央/侧颈淋巴结；是首选颈部影像。 | 国家卫健委 PDF 7–10；ATA 2025 PDF 16（期刊856） |
| FNA/病理 | 对符合穿刺指征的原发灶行超声引导FNA；对可疑淋巴结如结果会改变治疗，应FNA确认。DTC可选择性加FNA-Tg；疑MTC可加穿刺液Ctn/细胞块/免疫组化。 | 国家卫健委 PDF 8–16；ATA 2025 PDF 16；MTC共识 PDF 3 |
| 声音/声带评估 | 国内国家指南建议术前常规评估双侧声带活动；可行间接/纤维喉镜。ATA至少要求所有患者术前声音评估，并在声嘶、既往相关手术、后方侵袭或广泛淋巴结病时行喉镜。 | 国家卫健委 PDF 12；ATA 2025 PDF 29（期刊869） |
| 局部侵犯追加检查 | 疑气管侵犯：纤维支气管镜/气管镜；疑食管腔内侵犯：可考虑食管镜；必要时增强CT/MRI明确气管、食管、喉返神经、血管和纵隔关系。 | 国家卫健委 PDF 10–12；ATA 2025 PDF 17–18 |
| 增强CT/MRI | 临床怀疑局部晚期、肉眼ETE、巨大/侵袭性淋巴结、气道/消化道/纵隔受累时，颈部和纵隔增强CT/MRI作为超声补充。疑血管受累可CTA/MRA。 | ATA 2025 PDF 17；CSCO PDF 47（35） |

> 来源/页码：国家卫健委2022 PDF第4、7–12页；CSCO 2025 PDF第47页（指南书内第35页）；ATA 2025 DTC PDF第16–18页（期刊856–858）。
### 1.2 DTC（PTC/FTC/OTC）术前专病检查

| 场景 | 要点 |
|---|---|
| 必须完成 | 颈部超声完成cT/cN评估；可疑淋巴结FNA；根据临床/影像判断是否肉眼ETE。 |
| 不常规推荐 | ATA 2025不建议常规术前测血清Tg/TgAb；不建议对已确诊DTC常规进行体细胞基因组检测来决定手术范围；常规术前FDG-PET/CT不推荐。 |
| 何时做全身分期 | 当胸/腹/盆腔横断面影像结果会改变手术范围时选择性进行；远处转移并不自动取消甲状腺手术，因为可切除原发/区域病灶及后续RAI仍可能获益。 |
| 遗传评估 | 有提示遗传综合征/家族性非髓样甲状腺癌特征者，按ATA 2025遗传章节进行选择性胚系检测与遗传咨询。 |

> 来源/页码：ATA 2025 DTC：PDF第16–18页（术前超声/CT/MRI、Tg、基因、PET）；国家卫健委2022 PDF第11页。
### 1.3 MTC术前专病检查（必须单独执行）

| 项目 | 推荐 | 页码 |
|---|---|---|
| 血清Ctn + CEA | MTC确诊后术前同时检测；Ctn与肿瘤负荷相关，CEA可辅助评估侵袭/去分化。国内共识对可疑恶性甲状腺肿瘤也可考虑常规Ctn筛查。 | 中国MTC共识 PDF 3；国家卫健委 PDF 6 |
| RET胚系基因检测 + 遗传咨询 | 散发性MTC本人也推荐/可推荐筛查，因为部分“散发”病例实为遗传性；明确HMTC/MEN2并筛查一级亲属。 | 中国MTC共识 PDF 1–2；ATA MTC PDF 15 |
| PHEO筛查 | 确诊MTC特别是遗传性/MEN2，术前必须排除嗜铬细胞瘤；如并存PHEO，应先处理PHEO再进行甲状腺/MTC手术。 | 中国MTC共识 PDF 3–5；ATA MTC PDF 21 |
| HPTH筛查 | MEN2A应筛查甲状旁腺功能亢进；可结合血钙/PTH等。 | 中国MTC共识 PDF 3–5；ATA MTC PDF 15、21 |
| 颈部超声 | 所有MTC患者/可疑患者都应进行，评估原发灶和中央/侧颈区淋巴结。 | 中国MTC共识 PDF 3；ATA MTC PDF 15 |
| 系统影像 | 中国共识主张术前系统性影像评估；ATA 2015特别推荐在颈部病变广泛、存在区域/远处转移症状，或基础Ctn>500 pg/mL时做颈胸CT、肝脏增强CT/MRI、骨显像/轴位MRI。 | 中国MTC共识 PDF 3；ATA MTC PDF 15 |
| PET相关检查 | 不作为所有MTC常规首选；在Ctn高或倍增时间快、复发/转移评估时，可选择18F-FDG、18F-DOPA或68Ga-SSTR PET/CT。 | 中国MTC共识 PDF 3；国家卫健委 PDF 11 |


> **提示**
> MTC最重要的术前安全点
> 若MTC/MEN2合并嗜铬细胞瘤，PHEO必须优先处理。未排除PHEO前不应直接进行甲状腺手术，这是MTC与DTC围手术期最重要的差异之一。

### 1.4 ATC / DHGTC / PDTC术前追加检查
- ATC应快速完成局部可切除性、全身转移和气道风险评估。国家卫健委将PET-CT列为ATC疗前分期可考虑的检查。
- 出现声嘶、气促、喘鸣、吞咽困难或影像提示气管/食管侵犯时，及时行喉镜、支气管镜/食管相关评估，并同步制定气道管理预案。
- ATC的系统治疗与分子分型强相关。ASCO 2026的治疗推荐明确区分BRAF V600E、NTRK、RET等靶点，因此从治疗决策角度应尽早获得可操作的分子结果（这是由系统治疗推荐推导出的流程要求，而非ASCO单独列出的“术前检查推荐”）。
- PDTC/DHGTC属于滤泡上皮来源癌的高侵袭亚型，术前仍按DTC完成颈部/远处评估，但应提高对肉眼ETE、远处转移和较低RAI敏感性的警惕。
> 来源/页码：国家卫健委2022 PDF第11–12、24、35页；ASCO 2026 PDF第6页（系统治疗需按BRAF/NTRK/RET等分层）。
### 1.5 术前医嘱式检查清单（可直接用于科室路径）

| 对象 | 建议检查 |
|---|---|
| 所有拟手术患者 | 血常规、肝肾功能、甲状腺功能、凝血；甲状腺+全颈超声；病理/FNA；声音/声带评估 |
| 疑局部晚期/巨大淋巴结 | 颈部+纵隔增强CT或MRI；必要时胸部/其他部位影像；疑血管侵犯CTA/MRA |
| 疑气管/食管受侵 | 喉镜；支气管镜/气管镜；必要时食管镜/相应造影 |
| DTC | 一般不常规术前Tg/TgAb、FDG-PET/CT或体细胞基因检测；高危/侵袭性按需扩展 |
| MTC | Ctn、CEA、RET胚系检测/遗传咨询；PHEO筛查；MEN2A加HPTH筛查；系统性影像分期 |
| ATC | 快速全身分期+气道评估；尽早获得BRAF V600E等可操作分子信息 |


## 第二部分  手术指征、不宜手术情形及推荐术式

> **提示**
> 关于“手术禁忌证”的表述
> 这些指南没有提供一个适用于全部甲状腺癌的统一“绝对/相对手术禁忌证”表。本文件因此采用更准确的术语：“可暂缓手术”“不宜根治性手术/通常不可切除”“必须先处理的情况”和“某一具体术式应延期”。通用麻醉禁忌证另按围手术期规范评估。

### 2.1 DTC：PTC原发灶手术范围

| 临床情形 | 推荐术式/策略 | 页码 |
|---|---|---|
| cT1aN0M0，低危PTC（≤1 cm） | 主动监测可作为选择之一；若手术，腺叶切除通常足够。 | ATA 2025 PDF 19–22；国家卫健委 PDF 32–33；CSCO PDF 48（书内36） |
| ≤2 cm，cT1N0M0，无肉眼ETE | ATA 2025：首选甲状腺叶切除，除非双侧癌或另有切除对侧叶指征。CSCO 2025：无高危因素可患侧腺叶+峡部切除；存在远处转移、明确淋巴结转移、明显腺体外侵犯、分化差等可全/近全切。 | ATA PDF 22；CSCO PDF 48（36） |
| >2–4 cm，单侧低危cT2N0M0 | ATA 2025：腺叶切除可为优选，因并发症较低；根据疾病特征、对侧可疑结节、术后RAI/随访需要及患者偏好可全切。CSCO 2025亦将低危单灶无其他危险因素列为腺叶+峡部切除。 | ATA PDF 22；CSCO PDF 49（37） |
| >2–4 cm伴高危因素 | 全甲状腺/近全甲状腺切除。高危因素包括临床淋巴结/远处转移、肉眼ETE、分化差病理等；具体依指南风险定义。 | CSCO PDF 49（37）；ATA PDF 22 |
| >4 cm（cT3a） | 全甲状腺/近全甲状腺切除。 | ATA PDF 22；CSCO PDF 49（37） |
| 肉眼ETE（cT3b/T4）、cN1或cM1 | 全甲状腺切除，尽量完整切除原发灶，并对临床阳性淋巴结行分区治疗性清扫；局部侵袭者必要时联合切除受累结构。 | ATA PDF 22；国家卫健委 PDF 33–34 |
| 峡部癌 | 国家卫健委：小病灶可扩大峡部切除；病灶较大或伴淋巴结转移可考虑全切。 | 国家卫健委 PDF 32 |

> 最新趋势
> 2025 ATA较2015进一步支持低危DTC的去强化手术：≤2 cm cT1N0M0明确以腺叶切除为初始手术；2–4 cm单侧低危患者也可优先腺叶切除。是否全切应与后续RAI、随访便利性和对侧病变一起决策。以最新为准

### 2.2 FTC / OTC（嗜酸细胞癌）推荐术式

| 病理/临床情形 | 处理 |
|---|---|
| FTC广泛浸润型、包膜性血管浸润型（≥4处血管侵犯）、有转移或肿瘤>4 cm | CSCO 2025：甲状腺全切/近全切除。 |
| FTC微小浸润型、包膜性血管浸润型（<4处血管侵犯） | CSCO 2025：患侧腺叶+峡部切除可作为推荐方案。 |
| OTC | 原则接近FTC，但RAI敏感性往往更低；手术范围主要取决于侵袭/血管侵犯、大小、转移风险和是否需完成性切除。 |
| 术前细胞学为滤泡性肿瘤/可疑滤泡性肿瘤 | 最终是否FTC依赖包膜/血管侵犯的完整病理评估，因此常先行诊断性腺叶切除，再依据最终病理决定是否补全。 |

> 来源/页码：CSCO 2025：PDF第50页（指南书内第38页）；ATA 2025 DTC：PDF第22–25页。
### 2.3 DTC颈部淋巴结清扫

| 淋巴结状态 | 推荐 |
|---|---|
| cN1a | 治疗性中央区清扫。国家卫健委建议患侧中央区；ATA强调分区清扫，典型中央区包括VI及上VII。 |
| cN1b | 治疗性侧颈区分区清扫；常见范围IIa、III、IV、Vb，并结合中央区处理。 |
| cN0，小型非侵袭性cT1–T2 PTC | ATA 2025：不应常规行预防性中央区清扫。 |
| cN0，T3/T4或需病理结节信息指导后续治疗 | ATA 2025：可考虑预防性中央区清扫，但需权衡喉返神经/甲状旁腺风险。国家卫健委对T3–T4、多灶、家族史等高危cN0亦允许考虑。 |
| cN0侧颈区 | 不行预防性侧颈清扫；只有术前或术中证实N1b时治疗性清扫。 |

> 来源/页码：国家卫健委2022 PDF第33–34页；ATA 2025 DTC PDF第26–27页（Recommendation 19及治疗性清扫相关段落）。
### 2.4 DTC何时补全甲状腺切除
- 初次腺叶切除后发现持续原发恶性病灶、疑双侧癌，或需要为RAI/生化随访创造条件且术后复发风险升高时，可考虑completion thyroidectomy。
- 支持补全的高风险特征包括肉眼ETE、较高淋巴结负荷/ENE、广泛血管侵犯、侵袭性病理等。
- 单纯镜下ETE或单纯镜下切缘阳性并不自动等于必须补全；需结合整体复发风险。
- 如初次手术造成同侧喉返神经损伤，应评估神经功能；ATA 2025建议对侧切除延期至同侧神经恢复，以降低双侧声带麻痹风险。
> 来源/页码：ATA 2025 DTC PDF第24–26页（Recommendation 16及说明）。
### 2.5 DTC局部晚期与“不宜根治性手术”情形

| 情形 | 处理 |
|---|---|
| T4a，可切除 | 全甲状腺切除并联合切除受累结构；可涉及部分/全喉、气管、下咽/食管等，术前需规划重建。 |
| T4b | 国家卫健委：一般认为不可手术切除；个别病例可MDT评估是否存在手术机会。重点判断能否真正获益，必要时仅姑息减状。 |
| 无法完整切除且预计严重功能损失，或残留病灶不可避免 | 不宜为了“完成手术”而行高代价根治术；可转入EBRT、RAI（若摄碘）、系统治疗或姑息路径。 |
| 低危cT1a PTC | 可主动监测，因此“暂不手术”并非禁忌，而是指南认可的替代策略。 |
| 补全切除时同侧RLN损伤 | 对侧completion手术应延期至神经恢复/经高容量中心评估。 |

> 来源/页码：国家卫健委2022 PDF第33页；ATA 2025 DTC PDF第21、25、53–55页。
### 2.6 MTC：原发灶手术范围

| MTC情形 | 推荐术式/策略 | 页码 |
|---|---|---|
| 遗传性MTC / 明确RET胚系突变 / 明确家族史 | 全甲状腺切除。中国共识推荐等级A。 | MTC共识 PDF 4，推荐23 |

| 腺叶切除后意外确诊MTC | 国家卫健委通常建议补充全切；个别偶然发现的散发性微小MTC可密切观察。补全前应补做RET/MEN2及病情评估。 | 国家卫健委 PDF 34–35；MTC共识 PDF 7 |

### 2.8 MTC颈部淋巴结清扫

|---|---|
| cN0 | 全甲状腺切除 + 预防性中央区淋巴结清扫（中国共识推荐26；ATA MTC Recommendation 24）。 |

### 2.9 MTC不宜立即/不宜根治性手术的情形
- MEN2合并PHEO：必须先处理PHEO，再考虑MTC/甲状旁腺手术；这是明确的手术顺序要求。
- 局部晚期MTC若R0切除机会极低，且需以多器官功能丧失为代价，中国共识建议考虑临床试验或系统治疗，而非盲目扩大根治手术。
- 远处广泛转移时，颈部手术是否实施取决于局部症状、气道/吞咽风险和能否改善生活质量，而不是单纯追求生化治愈。
> 来源/页码：中国MTC共识2020 PDF第4–5页（推荐33–38）；ATA MTC 2015 PDF第21页（Recommendations 38–39）。
### 2.10 ATC手术指征与不宜手术情形

| ATC情形 | 推荐 |
|---|---|
| IVA / IVB，评估可手术切除 | CSCO 2025：可行全甲状腺/近全甲状腺切除（或术后偶然发现时补充全切），外科目标是尽量R0/R1，并纳入放疗/系统治疗的多模式方案。 |
| 局部肿瘤较小、可完整/近完整切除 | 国家卫健委：少数病例可能有手术机会。 |
| 颈部巨大、广泛侵犯、快速进展且不可切除 | 多数ATC无根治手术机会，应进入放疗/系统治疗/气道与症状管理。 |
| IVC期 | CSCO 2025：以姑息性外科干预或介入治疗为主，而非根治性甲状腺切除。 |
| 气道梗阻 | 必要时气管切开/其他气道处理以解除梗阻；应与整体治疗目标一致。 |

> 来源/页码：CSCO 2025 PDF第50页（书内第38页）；国家卫健委2022 PDF第35、61页。

## 第三部分  术后根据什么指征进行什么治疗

> **提示**
> 最重要的总原则
> 术后不能用同一套辅助治疗规则覆盖所有甲状腺癌：DTC的核心是“复发风险/治疗反应 → RAI + LT4/TSH + 选择性EBRT”；MTC的核心是“Ctn/CEA → 观察/影像/再手术/EBRT/RET导向系统治疗”，且不行RAI、不做肿瘤目的TSH抑制；ATC则强调尽快进入放疗/靶向/系统治疗的多模式方案。

### 3.1 DTC术后第一步：病理分期 + 复发风险 + 6–12周生化/影像评估
- ATA 2025建议用2025 ATA复发风险体系，结合AJCC分期、术后病理、淋巴结数量/负荷、术后影像和Tg/TgAb评估结构性持续/复发风险。
- 术后约6–12周在LT4状态下评估Tg/TgAb和必要影像，再决定是否RAI；6–12个月后再次按治疗反应动态分层。
- 国家卫健委2022仍以低/中/高危分层指导RAI，核心高危因素包括明显腺外浸润、未完整切除/残留、远处转移、高Tg提示转移、较大淋巴结转移及FTC广泛血管侵犯。
> 来源/页码：ATA 2025 DTC PDF第34、55页（Recommendation 28、DATA Framework）；国家卫健委2022 PDF第40–42页。
### 3.2 DTC：RAI（131I）治疗指征

| 术后情况 | 治疗 | 页码 |
|---|---|---|
| ATA低危DTC，全切后无明显残留/转移 | 不常规RAI。若个体化选择清甲，使用低剂量方案。 | ATA 2025 PDF 44–45；国家卫健委 PDF 42 |
| 低-中间/中-高间复发风险 | 考虑RAI辅助治疗；重点看侵袭性病理、淋巴结负荷/侧颈转移、血管侵犯、术后Tg、年龄等。 | ATA 2025 PDF 44–46 |
| 高危DTC | 常规推荐术后RAI。 | ATA 2025 PDF 44–46；国家卫健委 PDF 42 |
| 初诊有远处转移 | 全甲状腺切除后常规推荐RAI（若病灶具有/可能具有碘摄取性）。 | ATA 2025 PDF 44–47 |
| 已知摄碘性残留/复发/转移病灶 | 治疗性RAI（清灶）；肺/骨等按病灶和剂量学个体化。 | 国家卫健委 PDF 43–44 |
| OTC | RAI获益证据不确定；若不经验性给予，可先评估碘摄取。 | ATA 2025 PDF 47（Recommendation 33） |

### 3.3 DTC：RAI常用活动度与禁忌（速查）

| 情形 | 建议 |
|---|---|
| 低危（若确需清甲） | ATA 2025：30–50 mCi |
| 中间风险辅助治疗 | ATA 2025：30–100 mCi |
| 高危辅助治疗 | ATA 2025：100–150 mCi |
| 已知远处转移 | ATA 2025：100–200 mCi或剂量学；高龄、弥漫肺转移、肾功能异常更应考虑剂量学 |

> 来源/页码：ATA 2025 DTC PDF第45–47页（Table 10）；国家卫健委2022 PDF第42–44页。
### 3.4 DTC：LT4替代与TSH抑制

| 状态 | TSH策略 |
|---|---|
| 高危初治期 | 国家卫健委：TSH <0.1 mU/L。 |
| 中危初治期 | 国家卫健委：TSH 0.1–0.5 mU/L。 |
| 低危、全/近全切、Tg未检出 | TSH 0.5–2.0 mU/L。 |
| 低危、低水平Tg或部分需更强控制 | 可考虑0.1–0.5 mU/L。 |
| 腺叶切除 | TSH 0.5–2.0 mU/L。 |
| 结构性不完全反应 | 无禁忌时可维持TSH <0.1 mU/L。 |
| 生化不完全反应 | 结合初始风险、Tg趋势和抑制副作用，常为0.1–0.5 mU/L。 |
| 长期低/中危且无生化/结构复发 | ATA 2025：不建议长期维持低于参考范围的强TSH抑制；应随时间重新评估获益/风险。 |

> 来源/页码：国家卫健委2022 PDF第43–44页；ATA 2025 DTC PDF第55–56页（Recommendations 45–46）。

> **提示**
> 更新提醒
> 国内旧版数字目标便于速查，但ATA 2025更强调动态个体化：低/中危且无复发证据者不要长期“压得越低越好”，需同时考虑房颤、骨质疏松等副作用。

### 3.5 DTC / PDTC：什么时候术后加外照射

| 指征 | 处理 |
|---|---|
| 高局部复发风险DTC | 侵袭性病理、肉眼ETE、阳性切缘、脏器/软组织侵犯等，若未来复发难以挽救手术，可选择性考虑辅助EBRT。 |
| 术后肉眼残留/局部不可切除DTC | 可考虑EBRT ± 同步化疗以提高局部控制，但需权衡急慢性毒性。 |
| 肿瘤累及气管/喉/椎前/大血管等且手术未切净，RAI无效或预计效果差 | 国家卫健委：可考虑术后EBRT。 |
| PDTC/ATC术后残留或广泛淋巴结转移 | 国家卫健委：应及时考虑较大范围术后放疗。 |

> 来源/页码：ATA 2025 DTC PDF第53–55页（Recommendation 44）；国家卫健委2022 PDF第45–47页。
### 3.6 DTC术后随访与复发后治疗

| 随访/复发情形 | 处理 |
|---|---|
| Tg/TgAb | 全甲状腺清除后按风险/反应定期监测；国家卫健委建议同一方法/试剂并长期看趋势。 |
| 颈部超声 | 按风险进行术后超声；国家卫健委：高危约术后3个月，中低危约6个月首次；此后按异常与风险调整。 |
| 可疑颈部淋巴结 | 可行FNA + 洗脱液Tg；可切除结构性复发通常优先挽救手术。 |
| 摄碘性复发/转移 | RAI。 |
| 不摄碘或RAI无效、局部威胁 | 手术/EBRT/消融等局部治疗个体化。 |
| RAIR但无症状、稳定/缓慢进展 | 可观察，避免过早启动有毒性系统治疗。 |
| RAIR且临床进展或有症状 | 进入系统治疗路径。 |

> 来源/页码：国家卫健委2022 PDF第60–64页；ATA 2025 DTC长期管理章节。
### 3.7 RAIR-DTC / DHGTC / PDTC：系统治疗触发与选择

| 情形 | 系统治疗 |
|---|---|
| RAIR分化型癌，一线需要系统治疗 | ASCO 2026：仑伐替尼或索拉非尼；因现有疗效证据，仑伐替尼通常作为首选。 |
| 一线MKI后进展 | ASCO 2026：卡博替尼。 |
| NTRK融合 | 优先NTRK靶向：拉罗替尼或恩曲替尼；相较MKI可提前使用。 |
| RET融合 | 塞普替尼等RET靶向治疗。 |
| BRAF V600E | 可考虑BRAF/MEK相关靶向（ASCO为条件性推荐，需结合具体情形）。 |
| DHGTC/PDTC RAI难治 | 可考虑仑伐替尼/索拉非尼；有可操作基因改变时可考虑匹配靶向；免疫治疗证据较低，属条件性选择。 |

> 来源/页码：ASCO 2026系统治疗指南 PDF第5–6页；NCCN Guidelines Insights 1.2025 PDF第8–9页作为补充。药物可及性/适应证以本地监管批准为准。
### 3.8 MTC术后治疗：与DTC完全不同

| 术后指征 | 相应处理 | 页码 |
|---|---|---|
| 全甲状腺切除后 | 给予LT4替代，使甲状腺功能正常；不需要肿瘤目的TSH抑制。 | MTC共识 PDF 4，推荐31；国家卫健委 PDF 61、64 |
| 不伴DTC的MTC | 不行131I治疗。 | MTC共识 PDF 4–5，推荐32 |
| 术后3个月 | 检测Ctn + CEA评估手术疗效；正常/未检出者进入较低强度随访。 | MTC共识 PDF 7；ATA MTC PDF 24 |
| 术后Ctn/CEA持续升高或再次升高 | 计算倍增时间；中国共识建议至少连续4次、每次间隔至少6个月，随访间隔3–6个月。 | MTC共识 PDF 7，推荐50 |
| 术后Ctn <150 pg/mL（ATA） | 体检+颈部超声；如阴性，可6个月随访Ctn/CEA和超声。 | ATA MTC PDF 24，Recommendation 47 |
| 术后Ctn >150 pg/mL（ATA） | 扩大全身影像：颈部超声、胸CT、肝增强MRI/CT、骨显像及轴位骨MRI等。 | ATA MTC PDF 24，Recommendation 48 |
| 明确局部/区域残留或复发且可切除 | 考虑二次手术/分区颈清。 | MTC共识 PDF 7 |
| pT4、广泛ECE、R2/高局部复发风险 | 可考虑颈部/纵隔辅助EBRT，主要目的为局部控制；不等同于常规所有MTC术后放疗。 | 国家卫健委 PDF 46–47；MTC共识 PDF 4，推荐30 |

### 3.9 MTC晚期/不可切除/转移：系统治疗

| 情形 | 治疗 |
|---|---|
| 局部晚期不可手术 | 中国共识：可考虑临床试验或系统治疗；部分复发病灶可放疗。 |
| RET突变、需要系统治疗 | ASCO 2026：一线应给予塞普替尼（高质量证据，强推荐）。 |
| RET野生型、需要系统治疗 | ASCO 2026：一线卡博替尼或凡德他尼。 |
| RET靶向后进展 | 优先临床试验；无试验时可考虑凡德他尼/卡博替尼。 |
| 免疫治疗 | ASCO 2026：MTC不应在临床试验外常规使用免疫治疗。 |

### 3.10 ATC术后/后续综合治疗

| ATC情形 | 相应治疗 |
|---|---|
| 可切除IVA/IVB，完成R0/R1手术 | 尽快进入多模式治疗；放疗可作为术后综合治疗组成。国家卫健委建议ATC综合治疗并可高剂量放疗（约60 Gy，具体以放疗计划为准）。 |
| R2/不可切除局部病灶 | 以放疗 + 系统治疗/靶向治疗为主，目标局部控制和症状缓解。 |
| BRAF V600E突变 | ASCO 2026：一线强推荐达拉非尼 + 曲美替尼；部分病例可在MDT中用于术前转化或术后系统治疗。 |
| NTRK融合 / RET融合 | ASCO 2026：可考虑相应NTRK或RET靶向治疗。 |
| 无明确可靶向基因改变 | ASCO 2026：可考虑仑伐替尼；部分情况下可合并免疫治疗，证据较低，需个体化/临床试验。 |
| IVC / 远处转移 | 以系统治疗和症状导向的局部治疗为主；国家卫健委旧版化疗方案可作为历史国内路径，最新策略优先结合分子靶向和ASCO系统治疗推荐。 |

> 来源/页码：国家卫健委2022 PDF第47、55–58、61页；ASCO 2026 PDF第6页（Recommendations 9–12）。
### 3.11 DHGTC / PDTC术后特别提示
- 仍可根据碘摄取性和风险评估RAI，但总体应认识到其分化程度较低、RAI敏感性可能低于普通DTC。
- 术后有残留或广泛淋巴结转移时，国家卫健委支持及时考虑较大范围EBRT。
- RAI难治、复发/转移且需要系统治疗时，ASCO 2026允许仑伐替尼/索拉非尼以及按可操作基因改变匹配靶向治疗；免疫治疗属于低证据条件性选择。
> 来源/页码：国家卫健委2022 PDF第45页；ASCO 2026 PDF第5–6页。

## 第四部分  临床总表与路径
### 4.1 “术后病理/生化指征 → 下一步治疗”总表

| 类型 | 术后/疾病状态 | 下一步 |
|---|---|---|
| DTC | 低危、R0、无结构病灶 | 通常不RAI；LT4，TSH维持低正常/个体化；超声+Tg/TgAb随访 |
| DTC | 低-中间/中-高间风险 | 考虑RAI；依据侵袭性病理、淋巴结负荷、血管侵犯、Tg、年龄等决定 |
| DTC | 高危或远处转移 | RAI通常推荐；更密集影像/生化随访；TSH抑制按风险/反应 |
| DTC | 肉眼残留/阳性切缘+高局部风险/脏器侵犯且难再手术 | 选择性EBRT ± 同步系统治疗；同时评估RAI可能性 |
| DTC | RAIR且稳定/无症状 | 观察/局部治疗；不必立即系统治疗 |
| DTC | RAIR且进展/有症状 | MKI或基因靶向；按NTRK/RET/BRAF等分层 |
| MTC | 术后Ctn/CEA正常 | LT4替代，不抑制TSH；规律Ctn/CEA随访 |
| MTC | Ctn/CEA持续/再次升高 | 倍增时间 + 颈超；高水平/快速升高扩大全身影像 |
| MTC | 局部可切除复发 | 二次手术/分区颈清 |
| MTC | pT4/广泛ECE/R2/高局部复发风险 | 选择性EBRT |
| MTC | 不可切除/进展转移 | RET突变：塞普替尼；RET野生：卡博替尼/凡德他尼；临床试验 |
| ATC | R0/R1术后 | 尽快多模式：放疗 + 分子导向系统治疗 |
| ATC | R2/不可切除/IVC | 放疗/系统治疗/姑息与气道管理；按BRAF/NTRK/RET等靶点选择 |

### 4.2 “什么情况下先不要做根治性甲状腺手术”总表

| 类型 | 情形 | 策略 |
|---|---|---|
| DTC | 低危cT1a PTC且满足主动监测条件 | 可监测，不是必须立即手术 |
| DTC | T4b包裹大血管/椎前筋膜等，预期无法完整切除 | 通常不根治手术，MDT评估；必要时减状/非手术治疗 |
| DTC | completion前同侧RLN损伤 | 延期对侧切除至神经恢复/高容量中心评估 |
| MTC/MEN2 | 未排除或已确诊PHEO | 先处理PHEO，后做甲状腺手术 |
| MTC | 局部晚期、R0机会极低且需多器官功能牺牲 | 倾向系统治疗/临床试验±放疗，而非盲目扩大手术 |
| ATC | 巨大广泛不可切除/快速进展或IVC | 不以根治性手术为主；系统/放疗/气道与姑息 |

### 4.3 三条最实用的临床路径

> **提示**
> 路径A：DTC
> 病理确诊 → 甲状腺+全颈超声 → 判断cT、cN、肉眼ETE → 低危cT1a可主动监测；≤2 cm cN0M0多为腺叶切除；2–4 cm低危可优先腺叶切除；>4 cm/肉眼ETE/cN1/cM1全切+治疗性颈清 → 术后病理+Tg/TgAb/影像风险分层 → 低危通常不RAI，中间风险考虑，高危/远处转移RAI → 动态TSH目标 → 结构性复发优先可切除手术；RAIR进展再进入系统治疗。


> **提示**
> 路径B：MTC
> 疑/确诊MTC → Ctn+CEA → RET胚系检测/遗传咨询 → 筛PHEO（MEN2A同时筛HPTH）→ PHEO阳性先处理PHEO → 全甲状腺切除为主 + 中央区清扫；cN1b加受累侧颈清扫 → 术后不RAI、不做TSH抑制，仅LT4替代 → 3个月Ctn/CEA → 正常者低强度随访；升高者计算倍增时间、影像定位 → 可切除复发再手术；高局部风险EBRT；不可切除/转移按RET状态系统治疗。


> **提示**
> 路径C：ATC
> 快速病理确认 + 全身分期 + 气道评估 + 尽早分子分型 → MDT判断可切除性 → 可切除IVA/IVB争取R0/R1并迅速衔接放疗/系统治疗；不可切除/IVC不追求高代价根治手术 → BRAF V600E优先达拉非尼+曲美替尼，其他可操作靶点匹配靶向；无靶点进入其他系统治疗/临床试验，并全程关注气道和症状控制。


## 第五部分  关键差异与注意事项

| 议题 | 本文件处理方式 |
|---|---|
| DTC手术范围 | 国家卫健委2022与ATA/CSCO 2025总体方向一致，但ATA 2025对低危≤2 cm和2–4 cm患者更明确支持腺叶切除/去强化。本文以2025 ATA/CSCO更新内容为主，保留国家卫健委国内基础框架。 |
| cN0中央区清扫 | ATA 2025明确不建议大多数小型非侵袭性cT1–T2 cN0 PTC常规预防性清扫；对T3/T4可考虑。国家卫健委对高危cN0也允许考虑。本文不把预防性中央清扫写成所有PTC常规。 |
| MTC侧颈预防性清扫 | 中国共识认为大多数cN0无需预防性侧颈清扫，结合Ctn/中央区/肿瘤负荷；ATA 2015对完全按Ctn阈值决定未达共识。本文以“个体化考虑”呈现。 |
| TSH抑制 | 国家卫健委提供清晰数值目标；ATA 2025更强调动态调整和副作用，低/中危无复发证据者不建议长期强抑制。 |
| 药物治疗 | ASCO/NCCN为国际指南，药物适应证、可及性和报销应以中国最新监管批准及医院药事规定为准。 |
