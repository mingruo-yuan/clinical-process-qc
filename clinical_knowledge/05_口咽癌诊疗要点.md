# 临床诊疗要点参考（口咽癌）

## 主要依据文件
- 《CSCO头颈部肿瘤诊疗指南》口咽癌部分
- 文件：口咽癌诊疗要点整理

## 一、术前推荐检查
### 1. 头颈部专科检查
- 完整头颈部体格检查，明确原发灶部位、大小、是否接近或跨越中线。
- 重点评估扁桃体、舌根、软腭、咽后壁等口咽亚区受累情况。
- 评估下颌骨、舌深部肌群等邻近结构是否受侵。
- 检查颈部淋巴结的位置、大小、活动度及是否存在双侧转移。
> 来源/页码：CSCO PDF 第20页，书内第8页。
### 2. 原发灶与颈部影像学检查
- 原发灶增强CT：Ⅰ级推荐，用于评估原发灶范围、骨性结构及较大范围侵犯。
- 原发灶增强MRI：Ⅰ级推荐，尤其适合评估舌根、深部舌肌、咽旁间隙、翼肌、神经血管结构及黏膜下浸润。
- 颈部增强CT：Ⅰ级推荐，用于颈部淋巴结分期。
- 颈部超声：Ⅲ级推荐；对可疑淋巴结可结合超声引导下穿刺。
> 来源/页码：CSCO PDF 第20-22页，书内第8-10页。
### 3. 胸腹部及远处转移检查
- 胸部增强CT或胸部平扫CT：Ⅰ级推荐。
- 腹部超声或腹部增强CT：Ⅰ级推荐。
- PET/CT：Ⅱ级推荐，尤其适用于局部晚期、多发/较大颈部淋巴结、怀疑远处转移或常规影像难以明确者。
- 必要时可行骨扫描。
> 来源/页码：CSCO PDF 第20-22页，书内第8-10页。
### 4. 内镜检查及组织学确诊
- 电子鼻咽喉镜/纤维咽喉镜观察扁桃体、舌根、软腭、咽后壁及邻近下咽、喉部。
- 必要时在全麻下行更充分的检查和活检。
- 对可疑原发灶行经口或内镜下肿块活检，以获得组织学诊断。
- 以颈部转移性淋巴结为主要表现时，可行细针穿刺、粗针活检，必要时切取活检。
> 来源/页码：CSCO PDF 第20页，书内第8页；病理学诊断见 PDF 第25页，书内第13页。
### 5. p16/HPV检测（口咽癌重点）
- p16免疫组织化学检测：Ⅰ级推荐，是口咽癌的重要分层检查。
- 必要时可进一步行HPV DNA或HPV RNA检测：Ⅱ级推荐。
- p16阳性与p16阴性口咽癌采用不同的TNM分期体系，因此术前应明确p16状态。
> 来源/页码：p16/HPV检测：CSCO PDF 第25页，书内第13页；p16阴性分期：PDF 第38-41页，书内第26-29页；p16阳性分期：PDF 第42-43页，书内第30-31页。
### 6. 术前检查汇总表

| 类别 | 推荐检查 | 主要目的 |
|---|---|---|
| 专科 | 头颈部体检 | 评估原发灶及颈部淋巴结 |
| 内镜 | 电子鼻咽喉镜/纤维咽喉镜 | 明确口咽原发灶范围及邻近结构 |
| 病理 | 原发灶活检 | 明确组织学诊断 |
| HPV | p16 IHC | 口咽癌重要分层与分期依据 |
| HPV补充 | HPV DNA/RNA | 必要时进一步确认 |
| 原发灶 | 增强CT | T分期 |
| 原发灶 | 增强MRI | 深部软组织侵犯 |
| 颈部 | 颈部增强CT | N分期 |
| 淋巴结 | 超声±穿刺 | 可疑淋巴结定性 |
| 胸部 | 胸部CT | 肺转移/第二原发评估 |
| 腹部 | 超声或增强CT | 远处转移评估 |
| 全身 | PET/CT | 局部晚期/高危患者全身分期 |


## 二、手术指征、不宜手术情况及推荐手术方式
### 1. 早期口咽癌：T1-T2 N0
核心原则：手术或单纯放疗均可作为单一治疗模式，均为Ⅰ级推荐、2A类证据。
- 适宜手术者：可选择手术；也可选择单纯放疗。
- 不适宜手术者：单纯放疗。
> 来源/页码：CSCO PDF 第79页，书内第67页。
### 2. 早期口咽癌推荐手术方式
- 经口激光显微手术（TLM）：适合暴露良好、范围局限并可获得安全切缘的病变。
- 经口机器人手术（TORS）：适合暴露良好的扁桃体癌、舌根癌及局限性口咽病变。
- 开放性口咽原发灶切除：适用于经口暴露困难、病灶范围较大或TLM/TORS难以获得安全切缘者。
注意：CSCO强调术式选择应结合肿瘤大小、位置、术后功能影响、术者经验和患者选择。
> 来源/页码：CSCO PDF 第79页，书内第67页。
### 3. cN0早期口咽癌的颈部处理
- 口咽癌存在隐匿性颈淋巴结转移风险，原发灶手术时通常需同时处理颈部。
- 一般可行同侧Ⅱ-Ⅳ区选择性颈淋巴结清扫。
- 如肿瘤向前侵犯，可酌情处理Ⅰ区。
- 原发灶位于或接近中线（如软腭、舌根、咽后壁）时，应考虑对侧颈部处理。
- 如术前评估提示Ⅱa区无受侵，可不常规清扫Ⅱb区。
> 来源/页码：CSCO PDF 第80页，书内第68页。
### 4. 局部晚期口咽癌的手术指征
适用分期：T1-T2、N1-N3，或T3-T4、任何N。
- 适宜手术患者：Ⅰ级推荐可行手术±术后放疗/同步放化疗（2A类）。
- 同时，根治性同步放化疗也是重要的标准治疗选择。
- 是否选择手术需综合可切除性、能否获得阴性切缘、患者全身状态、预计功能损害以及颈部病变可否控制。
> 来源/页码：CSCO PDF 第81-82页，书内第69-70页。
### 5. 不适宜根治性手术的情况
指南原文没有单列“绝对手术禁忌证”表，而是以“不适宜手术”表述。主要包括：
- 患者身体条件不允许接受手术。
- 患者因各种原因拒绝手术。
- 肿瘤负荷过大，无法实现根治性切除。
> 来源/页码：CSCO PDF 第82页，书内第70页。
### 6. TORS/TLM不宜勉强实施的情况
指南未给出独立的TORS/TLM绝对禁忌证表。根据CSCO治疗框架，术式需综合：
- 肿瘤大小和位置。
- 是否能够获得安全切缘。
- 手术后可能造成的吞咽、语言等功能障碍。
- 医疗中心及术者经验。
- T3-T4或预计手术造成功能损害较大时，应认真比较同步放化疗，而不宜为追求手术而勉强实施经口微创手术。
> 来源/页码：CSCO PDF 第82-83页，书内第70-71页。
### 7. 局部晚期颈部手术
- 根据颈部转移程度实施相应治疗性颈淋巴结清扫。
- 可根据病变采用改良性或根治性颈清扫。
- N2c或存在双侧颈部转移时，应处理双侧颈部。
- 原发灶靠近中线（软腭、舌根、咽后壁等）时，应考虑对侧颈部淋巴结处理。
> 来源/页码：CSCO PDF 第83页，书内第71页。

## 三、术后根据何种指征进行何种治疗
### 1. 低危：术后观察
- R0切除。
- 早期病变。
- 无明确高危病理因素。
- 无明显脉管侵犯、周围神经侵犯、ENE或切缘问题。
处理：可考虑术后观察，不常规追加放疗。
### 2. 一般高危因素：术后单纯放疗
CSCO列出的常见一般高危因素包括：
- pT3-pT4。
- pN2-pN3。
- 颈部Ⅳ区或Ⅴ区淋巴结转移。
- 脉管侵犯（LVI+）。
- 周围神经侵犯（PNI+）。
处理：推荐术后放疗，并尽量在术后6周内开始。
> 来源/页码：CSCO PDF 第83页，书内第71页。
### 3. 最高危因素：术后同步放化疗
- 切缘阳性，或切缘不足/极近切缘。
- 淋巴结包膜外侵犯（ENE+）。
处理：推荐术后同步放化疗，而不是单纯放疗。
提示：指南所引用研究表明，淋巴结ENE和/或镜下手术切缘距肿瘤＜1 mm的患者，术后同步放化疗较单纯放疗可获得更好的生存获益。
> 来源/页码：CSCO PDF 第83页，书内第71页。
### 4. 术后辅助治疗决策表

| 最终术后病理/风险因素 | 推荐术后处理 |
|---|---|
| R0、早期、无高危因素 | 观察 |
| pT3-pT4 | 术后放疗 |
| pN2-pN3 | 术后放疗 |
| Ⅳ/Ⅴ区淋巴结转移 | 术后放疗 |
| LVI+ | 术后放疗 |
| PNI+ | 术后放疗 |
| 切缘阳性 | 同步放化疗 |
| 切缘不足/极近切缘 | 倾向同步放化疗 |
| ENE+ | 同步放化疗 |
| ENE+且切缘阳性 | 明确同步放化疗 |

### 5. 术后放疗剂量
对于早期口咽癌术后存在高危因素需辅助治疗时，术后放疗剂量通常约 60-66 Gy，具体剂量及靶区需结合病理风险分层和放疗计划个体化确定。
> 来源/页码：CSCO PDF 第80页，书内第68页。
### 6. p16/HPV阳性患者能否常规降阶治疗？
结论：不能仅因p16/HPV阳性就常规降低术后治疗强度。
- HPV阳性口咽癌总体预后通常优于HPV阴性口咽癌。
- 目前虽有TORS、降低放疗剂量/范围、减弱系统治疗等降阶研究，但CSCO指出仍缺乏足够大型随机研究证据。
- 临床仍应依据T/N分期、切缘、ENE、LVI、PNI、淋巴结负荷和患者因素综合决定术后治疗。
> 来源/页码：CSCO PDF 第84页，书内第72页。

## 四、临床简化路径
术前：病理确诊 → p16检测 → 原发灶CT/MRI → 颈部增强CT → 胸部CT → 必要时PET/CT。
早期 T1-T2 N0：手术或根治性放疗均可；手术病例可根据条件选择TORS/TLM或开放手术，并结合颈部选择性清扫。
局部晚期：MDT判断可切除性。可手术者行手术±术后辅助治疗；不适宜手术者进入根治性放疗/同步放化疗路径。
术后：无危险因素→观察；一般高危因素→术后放疗；切缘阳性/不足或ENE阳性→术后同步放化疗。
